# 3D Warehouse Visualization System — Documentation Guide

**Project:** 3D Smart Warehouse
**Role:** Technical Writer & Developer
**Audience:** Warehouse staff with no technical background
**Goal:** Make an internal tool accessible to all employees

---

## What This System Does

3D Smart Warehouse is a visualization and inventory management system. It allows warehouse workers to find the exact location of goods in a three-dimensional warehouse space of 738 m² (41×18 m) in real time.

**Key features:**
- 3D visualization of all warehouse sections
- Real-time search by product name or code
- Integration with 1C and Excel for inventory tracking
- Simple interface — no technical skills required

---

## How to Use It

### Step 1: Open the system

Open the link provided by your manager. You will see a 3D model of the warehouse with colored sections.

### Step 2: Search for a product

In the search bar at the top, type:
- The product name (e.g., "Brake pads")
- Or the product code (e.g., "BP-2024-01")

The system will highlight the shelf where the product is located.

### Step 3: View product details

Click on the highlighted shelf. You will see:
- Product name and code
- Quantity in stock
- Date of last inventory
- Supplier information

### Step 4: Update inventory

If you need to update stock levels:
1. Click the **"Edit"** button
2. Enter the new quantity
3. Click **"Save"**

The changes will be automatically synced with 1C and Excel.

## Troubleshooting

### "Product not found"
- Check the spelling of the product name
- Try searching by product code instead
- If it still doesn't appear, contact your manager to check if the product has been added to the system

### "Loading..." screen stays on
- Check your internet connection
- Refresh the page (F5)
- If the issue persists, restart your browser

### "Access denied"
- This message appears when you try to edit a product without permission. Only authorized staff can update inventory. If you need access, ask your manager to add you.

## Tips for New Users

- **Start with a simple search** — Type the product name and see where it appears
- **Click around** — The 3D view is interactive. You can rotate and zoom by dragging the mouse
- **Ask your team** — If you're unsure about something, your colleagues have been using this system for weeks. They're happy to help
